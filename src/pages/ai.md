I use AI when I need to look something up that would be tedious to hunt down manually (deep research mode).

A lot of what I write is docs, and I help run [Write the Docs India](https://write-the-docs-india.github.io/), so Alex Garnett's [talk at Write the Docs Portland](https://www.writethedocs.org/conf/portland/2025/speakers/#speaker-alex-garnett-docs-ai-tooling-is-better-and-better-for-us-than-you-think-alex-garnett) hit home: "Docs AI tooling is better—and better for us—than you think." I use these tools for writing too, as _tools_, not as replacement writers. I bring the material and decide the argument and the outline. A model is part of the process after that; I edit each line and answer for what I publish.

**The rule: if I can't explain it in my own words, I don't write about it.** My name is on the post, so I'm the one who has to answer when a reader asks "wait, is this right?"

I wrote the longer version of this in [Somebody has to read it](/posts/somebody-has-to-read-it/).
